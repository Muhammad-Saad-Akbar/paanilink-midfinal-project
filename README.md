# PaaniLink · Phase 1 Frontend

Complete HTML5/CSS3/vanilla-JavaScript water tanker booking and dispatch demonstration.

**Run:** Open a terminal in this folder and run `python -m http.server 8000` (Windows: `py -m http.server 8000`), then visit `http://localhost:8000`.

**Start here:** [`docs/README.md`](docs/README.md) · [`docs/SYSTEM_FLOW.md`](docs/SYSTEM_FLOW.md) · [`docs/API_CONTRACT.md`](docs/API_CONTRACT.md) · [`docs/ASSUMPTIONS.md`](docs/ASSUMPTIONS.md) · [`docs/VIVA_GUIDE.md`](docs/VIVA_GUIDE.md).

Optional tests: `node --test tests/rules.test.js` (requires Node.js only for tests).

**Demo accounts:** click any role on the login page and log in with `demo123`. Do not enter real CNIC or identity documents; the data is fictitious and browser-local.

**Important:** the group variation rule has not yet been supplied and is not represented as implemented. This prototype does not include backend authentication, payments, database transactions or cross-device synchronization.
